# Offline backup movies (no network needed)
Generated by `cd pipeline && ../.venv/Scripts/python.exe -m skylapse_pipeline movies` from `web/public/bundle/<field>/` (sequence `thermal46` = WISE W2 4.6 µm 2010–2024 + SPHEREx D6 4.4–5.0 µm 2025–2026).
- `<field>_thermal46.mp4`: 1080×1080, 4 fps, H.264; the last frame is held for 1 s.
- `<field>_thermal46.gif`: ≤ 4 MB, for slides.
- North is up and East is left. The green ring follows the target: its measured track when science has written one, otherwise its catalogue proper motion (the footer says which).
- Frames use one asinh stretch per instrument. Brightness is "relative" and is not photometry.
- `wise0855_first_last.png`: May 2010 vs Nov 2025. WISE 0855 moved about 2′ west.
Data credits: NASA/IPAC IRSA SPHEREx, unWISE via byw.tools (Backyard Worlds/AMNH), NASA WISE/NEOWISE.
